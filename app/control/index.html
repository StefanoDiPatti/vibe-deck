        Pulsanti e nuove pagine
        
          
        Una pagina nuova è un file in config/pages/<id>.json; per cambiare una pagina predefinita copiala da config/defaults/pages/ (o da official-plugins/<id>/pages/) a config/pages/. Le app stanno in config/apps.json (o config/apps/<id>.json), i comandi in config/commands.json. Il tablet si aggiorna da solo quando salvi. Pagina nuova: npm run new:page -- <id>; widget nuovo (plugin in plugins/<nome>/): npm run new:widget -- <nome>. Esempi nella guida per sviluppatori del README.
